SMA Survey — cara pakai

  • Navigator: File › Set work directory untuk folder kerja (mis. D:\yopi), Tambah folder server (baca saja) untuk Z:\. Klik dua kali file untuk membuka (DTM otomatis membuka .str-nya), seret file ke layar grafis, klik kanan untuk menu (folder simpan, folder baru, ganti nama, hapus). Folder yang dipilih di Navigator menjadi folder simpan hasil. Folder server tidak pernah ditulisi.
  • Buka file: pilih .str (teks/biner), .dtm (pilih bersama .str-nya) dan .shp. Bisa juga seret file ke layar. File hanya dibaca di komputer ini, tidak dikirim ke mana pun.
  • Mouse (seperti Surpac): roda = zoom di kursor, tombol tengah seret = geser, tombol kanan seret = putar (dari Plan langsung ke 3D). Seret kiri juga menggeser (untuk touchpad), Ctrl + seret kiri = putar.
  • Memilih: tanpa fungsi aktif, klik garis = pilih segmen (Shift/Ctrl + klik = tambah), klik dua kali = seluruh string. Klik kanan = menu (properti, pilih string, zoom, salin ke Excel, simpan .str, sembunyikan). Esc = batal pilih.
  • Fungsi: pilih fungsi dulu (Point properties I, Bearing and distance M), ikuti petunjuk di status bar kiri bawah. Kursor menempel ke titik terdekat (kotak putih). Esc atau klik kanan › Selesai = akhiri fungsi; di Bearing and distance Esc pertama mengakhiri garis, Backspace membatalkan titik terakhir.
  • Identify: klik titik → nomor string, Y, X, Z, deskripsi. Ukur: klik beberapa titik → jarak datar, miring, bearing, grade; di atas DTM juga jarak mengikuti permukaan DTM.
  • Salin ke Excel: tabel disalin, tinggal Ctrl+V di Excel. Simpan .str: titik yang dipilih/diukur disimpan sebagai string file Surpac.
  • Layer: centang untuk tampil/sembunyi, klik kotak warna untuk ganti warna, klik ▸ untuk daftar nomor string.
  • Section: buat garis di mode Ukur, lalu Buat section (semua DTM yang tampil).
  • DTM: CREATE DTM dari string file (aturan sama dengan Surpac) dan String over DTM (SOD) untuk jalan/distance.
  • Volume: DTM cut/fill per segmen boundary, sama dengan report Surpac. Isi nett kemarin untuk volume hari ini.
  • TXT ke STR: Survey › TXT ke STR, pilih folder data mentah (atau klik dua kali file .txt di Navigator). Periksa tebakan area dan profil di tabel, lalu Proses: crest/toe, spot, boundary, jalan, exca, dan file _CEK.str dibuat otomatis.
  • Proses Harian (di jendela TXT ke STR): satu klik untuk TXT → STR → update global + boundary → CREATE DTM → volume (base → global baru di dalam boundary baru, dan kemarin: base → global lama di dalam boundary lama) → report + riwayat. Global lama dicari otomatis (YYYY_MM_DD_update_topo_<area>.str terbaru sebelum tanggal proses) di folder kerja; base dipilih sekali per area dan diingat di sma_harian.json.
  • Update: update harian (potong global + tambah harian + boundary), potong progress, atau boundary tambah/kurangi. Hasil langsung jadi layer; simpan ke folder pilihan.
  • Kursor 3D & snap (seperti Surpac): posisi kursor ditentukan mode snap — 1 Bidang (perpotongan dengan bidang aktif, default horizontal Z 0; ganti di status bar atau klik kanan › Bidang aktif), 2 Titik (titik string terdekat), 3 Garis (posisi di garis string terdekat), 4 Segitiga DTM (permukaan DTM di bawah kursor). Ganti snap dengan tombol 1–4 atau klik kanan saat fungsi aktif. Di 3D kursor digambar sebagai silang sumbu X/Y/Z. View › Select camera target (atau klik kanan › Pusat putar di sini) memilih titik pusat putar.
  • Tombol: F zoom semua, P plan, 3 tampak 3D, I point properties, M bearing and distance, Esc selesai / batal pilih.
