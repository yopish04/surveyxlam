SMA Viewer — cara pakai

  • Buka file: pilih .str (teks/biner), .dtm (pilih bersama .str-nya) dan .shp. Bisa juga seret file ke layar. File hanya dibaca di komputer ini, tidak dikirim ke mana pun.
  • Plan: seret kiri = geser, roda = zoom di kursor. 3D: seret kiri = putar, seret kanan / Shift+seret = geser.
  • Identify: klik titik → nomor string, Y, X, Z, deskripsi. Ukur: klik beberapa titik → jarak datar, miring, bearing, grade; di atas DTM juga jarak mengikuti permukaan DTM.
  • Salin ke Excel: tabel disalin, tinggal Ctrl+V di Excel. Simpan .str: titik yang dipilih/diukur disimpan sebagai string file Surpac.
  • Layer: centang untuk tampil/sembunyi, klik kotak warna untuk ganti warna, klik ▸ untuk daftar nomor string.
  • Tombol: F zoom semua, P plan, 3 tampak 3D, I identify, M ukur, Esc selesai ukur.
